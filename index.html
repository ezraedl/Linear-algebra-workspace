Row operations

R1 <-> R2 swap rows
R2 = R2 - 3R1 add a multiple of another row
R1 = 2R1 multiply a row
R3 = R3 / (a+1) divide a row (if factor ≠ 0)
R1 = R1 + (a/2)R2 symbolic coefficient
Operations apply to the entire row, including the solution column. Press ↑ in the empty box to recall the last command.

Start matrix

Use entries such as 2, -3/4, a, 2a-b, or (a+1)/2. Arrow keys move between cells (Enter moves down). The start matrix locks after the first operation. Delete all later steps to edit it again.

Symbolic expressions are simplified algebraically where possible. In finite fields, highlighted cells show the modular calculation when you hover or tap them; coefficients are reduced modulo p, and division by symbolic expressions assumes they are nonzero.
