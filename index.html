Linear algebra workspace

Gaussian elimination, one step at a time.

Enter numbers or symbolic variables, apply row operations, and scroll through every intermediate matrix.

Offline-ready · No sign-in · Fixed

1. Define your matrix

Ordinary rational and symbolic arithmetic.
Use entries such as 2, -3/4, a, 2a-b, or (a+1)/2. Use the arrow keys to move between cells (Enter moves down). Press Start after editing the initial matrix.

2. Apply one row operation

Enter a command or select an example.
Supported syntax:

R1 <-> R2 swap rows
R2 = R2 - 3R1 add a multiple of another row
R1 = 2R1 multiply a row
R3 = R3 / (a+1) divide a row (if factor ≠ 0)
R1 = R1 + (a/2)R2 symbolic coefficient

Operations apply to the entire row, including the solution column.

3. Step-by-step history

0 steps
Hover or focus a highlighted matrix cell to see the modular calculation. Scroll horizontally to compare matrices. Every successful operation creates a new card; Undo removes the most recent card. Symbolic expressions are simplified algebraically where possible. In finite fields coefficients are reduced modulo p; division by symbolic expressions assumes they are nonzero.
